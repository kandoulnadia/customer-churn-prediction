# Customer Churn Prediction System using databriks

## Project Overview

This project aims to predict customer churn using Machine Learning techniques on a customer behavior dataset.

The system analyzes customer activity, subscription information, payment behavior, and support interactions to identify customers at risk of leaving the service.

The project was developed using Databricks, PySpark ML, SQL analytics, dashboards, and Gradio for the interactive interface.

1. Data Cleaning
2. Feature Engineering
3. Categorical Encoding

5. Train/Test Split

## Dashboard Analytics

The project includes dashboards to analyze:

* Churn distribution
* Support calls impact
* Subscription type behavior
* Payment delay influence
* Customer engagement patterns

---

## Interactive Interface

A Gradio interface was created to simulate a business AI application where users can input customer information and receive churn risk predictions in real time.
